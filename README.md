# 雅思真题在线

按试卷排版练习听说读写：翻 PDF、点题号定位、标答案、听听力、收生词。视觉和题目都是原创的，不使用任何现成真题站的代码、样式或文案。

目录里的三套卷是本站写的模拟题（学术类两套、培训类一套）。城镇、人物和图表数字都是虚构的，不是剑桥雅思，也不是官方样题的拷贝。你可以在登录后导入自己的 PDF，文件只留在这台浏览器里。

## 本地运行

```bash
npm install
npm run dev
```

打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

```bash
npm test
npm run lint
```

重新生成试卷 PDF、听力音频和 JSON：

```bash
npm run samples
```

这一步需要 Python、PyMuPDF、edge-tts 和 ffmpeg，并且要能访问语音合成服务。生成结果已经放在 `public/samples` 和 `data`，日常开发不必重跑。

## 现在能做什么

- 首页、目录筛选（学术类 / 培训类、纸笔 / 机考、科目）
- 试卷页：PDF 翻页、题号定位、答题卡、选择和填空、本地进度
- 听力：播放、倍速、后退 10 秒、段落标记、题号跳转
- 纸笔 / 机考两种看法
- 浅色、深色、护眼
- 生词本：加入、搜索、删除、导出 CSV / Anki
- 口语提示卡、准备计时、录音和自评
- 写作字数、计时、草稿
- 本机账号。会员解锁只写在这台浏览器，用来验收「对答案 / 范文 / 释义」门控

支付、云同步和数据库还没有接。进度键名是 `ielts:progress:<paperId>`。

## 部署

这是 Next.js App Router 项目，可以直接部署到 Vercel。构建命令 `npm run build`，不需要环境变量。

本机账号和会员状态都在浏览器里，换设备不会跟着走。
